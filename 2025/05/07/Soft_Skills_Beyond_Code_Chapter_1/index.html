软技能-代码之外的生存指南_其一

S SuHang · 游戏开发手记

为什么这本书与其他软件相关书籍截然不同？

  1. 多数软件开发的书籍都是有关于代码开发本身
  2. 本书主要解决“如何成为一名优秀的软件开发者”这个问题
  3. 本书讨论什么：
    • 关于你自己
    • 作为一名软件开发者，如何超越编写代码本身
  4. 本书不讨论什么：
    • 代码本身
    • 代码的质量
    • 代码的设计
    • …你能做什么

篇章

  1. 职业
  2. 自我营销
  3. 学习
  4. 生产力
  5. 理财
  6. 健身
  7. 心态
