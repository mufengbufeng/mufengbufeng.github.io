什么是托管代码

托管代码就是：其执行由运行时管理的代码。这种情况下，无论实现（如：Mono、.Net Framework、.Net Core/.Net 5+），都被称为公共语言运行时（CLR）。CLR 负责获取托管代码，将其编译为机器码，然后执行它。它还提供了多个重要服务，例如自动内存管理、安全边界和类型安全性。

相反，C/C++ 程序被称为”非托管代码”。在非托管的世界中，程序员几乎负责一切。程序本质上是二进制文件，由操作系统将其加载到内存并启动。其他一切，从内存管理到安全考量，都是由程序负责。

托管代码是可以在 .Net 上运行的高级语言编写的（如 C#、Visual Basic、F# 等），使用各自编译器编译代码时，不会得到机器码，而是得到中间语言代码 IL（中间语言），然后由运行时编译和执行。C++ 是这条规则的一个例外，因为它还可以生成在 Windows 上运行的本机非托管二进制文件。
