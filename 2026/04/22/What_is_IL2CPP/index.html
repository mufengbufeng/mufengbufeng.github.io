介绍

IL2CPP（Intermediate Language To C++）是 Unity 的脚本后端，可在为各个平台构建项目时替代 Mono。使用 IL2CPP 构建项目时，Unity 会在为所选平台创建本机二进制文件（例如 .exe、.apk、.xap）之前，将脚本和程序集内的 IL 代码转换为 C++。IL2CPP 有助于提高 Unity 项目的性能、安全性和平台兼容性。

IL2CPP 的组成

IL2CPP 技术包括两个部分：

  • AOT 编译器
  • 支持虚拟机的运行库

AOT 编译器可将 .NET 编译器的低级输出，即 IL，翻译成 C++ 源代码。运行库提供垃圾回收、独立于平台的线程和文件访问，以及内部调用（直接修改托管数据结构的本地代码）等服务与抽象。

AOT 编译器

IL2CPP AOT 编译器名为 il2cpp.exe。在 Windows 系统中，可以在 Editor\Data\il2cpp 目录中找到它；在 macOS 上，它位于 Unity 安装目录下的 Contents/Frameworks/il2cpp/build 目录。

il2cpp.exe 是一个完全用 C# 编写的托管可执行文件。在开发 IL2CPP 的过程中，Unity 使用 .NET 和 Mono 编译器对其进行编译。该工具接收由 Unity 附带 Mono 编译器编译的托管程序集，生成 C++ 代码，再交给特定平台的 C++ 编译器。

运行时库

IL2CPP 技术的另一部分是支持虚拟机的运行库。该库几乎完全由 C++ 实现，只有少量特定平台的汇编代码。运行时库称为 libil2cpp，并作为静态库链接到 Player 可执行文件中；其优势之一是简单且可移植。

通过 Unity 随附的 libil2cpp 头文件，可以了解运行时库的组织方式。例如，Windows 上的头文件位于 Editor\Data\PlaybackEngines\webglsupport\BuildTools\Libraries\libil2cpp\include，macOS 上位于 Contents/Frameworks/il2cpp/libil2cpp。il2cpp.exe 生成的 C++ 代码与 libil2cpp 运行时之间的接口位于 codegen/il2cpp-codegen.h。

运行时的一个关键部分是垃圾回收器。Unity 5 使用了 Libgc（Boehm-Demers-Weiser 垃圾收集器）；libil2cpp 的设计也允许替换为其他垃圾收集器。
