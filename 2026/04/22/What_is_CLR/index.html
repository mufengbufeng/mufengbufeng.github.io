热更新系列-03-CLR是什么

S SuHang · 游戏开发手记

CLR 是什么

.Net 的运行时环境，类似于 Java 的 JVM。

CLR 做什么

  • JIT 编译
  • 内存管理
  • 类型系统
  • 异常处理
  • 安全校验

CLR 有哪些实现

  1. CoreCLR

    • 微软官方的 CLR 实现
    • .Net 6/7/8/9 的核心运行时

  2. Mono

    • 早期第三方 CLR 实现
    • 后被微软收购
    • 现在是 .Net 官方运行时之一

  3. .Net Framework CLR

    • 仅支持 Windows 平台
    • 仅维护模式
