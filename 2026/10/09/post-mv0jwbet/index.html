关于英语长句

S SuHang · 游戏开发手记

阅读英语文章

阅读英语单词重要的不是认识每一个单词，而是学会寻找句子的主干，再逐步理解其他部分。

先分意群

  1. 主语 + 谓语尽量放在一起
  2. 介词短语通常可以单独成组
    常见介词：in, on, at, with, by, from, to, under
  3. 遇到连接词考虑分段
    如： but, because, when, if
  4. 遇到从句，识别它的整理意思
    常见从句引导词：taht, which, who, where, when, because

找出句子主干

谁（主语）+ 做了什么（谓语）+ 对谁做（宾语）
