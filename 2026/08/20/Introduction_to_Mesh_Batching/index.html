网格批处理简介

Batching（批处理）是一种优化 draw calls 的方式，它将相同 Material 的 Mesh 合并在一起，以便 Unity 可以使用更少的渲染状态来渲染它们。批处理可以提高性能、内存效率、并减少 CPu 开销，从而带来更流程的帧率和更好的玩家体验

批处理有以下限制：

  • 批处理仅支持 Mesh Renderers。 不支持 Skinned Mesh Renderers
  • 透明对象批处理可能会受到限制，因为 Unity 在批处理之前会将所有网格从后到前排序
  • Unity 无法使用 dynamic batching（动态批处理）将 Transform 组件中使用负缩放的 GameObject 和使用正缩放的 GameObject 进行批处理

Batch static GameObjects

静态批处理会将多个静态网格合并为一个顶点缓冲区和一个索引缓冲区，并使用世界空间坐标。每个缓冲区最多可包含 64,000 个顶点，但 Unity 可以创建多个批次。

在构建时批量处理静态网格

要在构建时批处理游戏对象，需要启用 static batching。

  1. Editor > Project Settings > Player 并启用 Statatic Batching.

  2. 在场景视图或层级视图中，选择需要批处理的对象，在 Inspector 窗口中启用 Batching Static。

Batch moving GameObjects

警告：对于大多数用途，不再推荐使用动态批处理，因为 CPU 开销可能大于绘制调用的开销。有关更多信息，请参阅选择绘制调用优化方法。
动态批处理仅建议在低端设备上使用。它在运行时执行以下操作：

  • 在 CPU 而非 GPU 上将网格顶点变换到世界空间，并将它们分组到一次绘制调用中
  • 对于运行时生成的几何体，如粒子、线条和轨迹，Unity 会将所有网格合并到一个顶点缓冲区中，然后为每个网格提交一次绘制调用。这与静态批处理类似。
