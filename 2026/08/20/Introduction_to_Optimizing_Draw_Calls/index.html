优化 draw calls 简介

S SuHang · 游戏开发手记

Unity - 手册：优化绘制调用简介 — Unity - Manual: Introduction to optimizing draw calls
优化 Draw Calls 是通过减少 CPU 向 GPU 发送信息的频率来加速渲染。

默认情况下，每个 mesh 都需要自己调用 draw call。 一次 draw call 包含以下步骤：

  • 更新渲染状态。CPU 使用图形 API 准备并发送 GPU 绘制网格所需的一切内容，如：Shader 代码、Texture、buffers 。 这部分是 CPU 最密集的步骤
  • 提交 draw call。 CPU 使用图形 API 告诉 GPU 要绘制什么。

使用 draw calls 优化系统，Unity 会把使用相同渲染状态的数据和网格分组。因此，Unity 更新渲染状态的频率降低，并在单个 draw call 中提交多个对象。

使用 optimizing draw calls 有以下好处：

  • 改善帧时间，或增加每一帧可渲染的 GameObject 数量
  • 减少应用所需的电量，可以降低需要电池供电设备的耗电速度

优化 draw call 类型

Unity 中 draw call optimization 方法通过以下方式之一工作：
- 利用 GPU 的硬件能力，在一次 draw call 调用多个副本。这就是 GPU instancing
- 使用其他技术减少渲染状态更新，例如大的 GPU 缓冲区。这就是 SRP Batcher 的工作原理
- 合并使用相同渲染状态的网格并一起绘制。这就是 batching
